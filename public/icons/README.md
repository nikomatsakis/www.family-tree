# PWA Icons

You need to add these icon files for the PWA to work properly:

- `icon-192x192.png` - 192x192 pixel app icon
- `icon-512x512.png` - 512x512 pixel app icon

These should be simple, recognizable family tree icons that work well on mobile home screens.

You can create these using:
1. Any image editor (GIMP, Photoshop, etc.)
2. Online icon generators
3. Simple tree/family symbols that represent your family

The icons should have:
- Transparent or white background
- Simple, clear design that works at small sizes
- High contrast for visibility on various home screen backgrounds
